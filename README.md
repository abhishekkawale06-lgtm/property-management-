# Property Management System

A PG and property management application with a Python Flask backend, SQLite database, and Vanilla JavaScript/HTML/CSS frontend.

## Quickstart

### 1. Install Python Dependencies
```bash
pip3 install -r requirements.txt
```

### 2. Start the Application

You can start the server using either npm or python:

```bash
npm start
# or
npm run dev
# or
python3 server.py
```

The application will be accessible at:
https://property-management-two-lake.vercel.app
